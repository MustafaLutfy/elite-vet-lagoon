العلامات وخريطة الكود

data-ds على كل مكوّن

كل عنصر قابل لإعادة الاستخدام في ملفات التصميم يحمل علامة data-ds باسم مكوّنه، ومعها data-ds-variant وdata-ds-tone وdata-ds-size عند الحاجة.

العلامة ليست زخرفة: الشكل كله يأتي منها، فأي عنصر يحمل الاسم يبدو كالمكوّن تمامًا. وعند البناء يصبح الاسم مكوّن React واحدًا.

<button data-ds="Button"
  data-ds-variant="primary">
  مريض جديد
</button>

// grep data-ds="StatusPill" ← every pill to build
